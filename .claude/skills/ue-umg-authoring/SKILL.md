# WBP 만들기

- **팩토리만으로는 루트 위젯이 없다.** `bUseWidgetTemplateSelector` 가 꺼져 있으면 `RootWidgetClass = DefaultRootWidget`(이 프로젝트는 없음)로 덮는다
  [소스 `WidgetBlueprintFactory.cpp:184`]. → `WidgetTree->ConstructWidget<UCanvasPanel>` + `RootWidget` 지정 + `OnVariableAdded`(§12-1 A7).
- **위젯 이름 → GUID 맵을 맞춘다.** 맵이 비어 있으면 컴파일러가 결정적 GUID 로 채우지만(`WidgetBlueprintCompiler.cpp:768`), 비어 있지 않은 WBP 에 위젯을 더하고
  알리지 않으면 `ensureAlways`(`:795`)가 터진다 [소스]. → 더할 때 `OnVariableAdded`, 지울 때 `OnVariableRemoved`, 이름을 바꿀 때 `OnVariableRenamed`(`WidgetBlueprint.h:259`).
- **트리를 고칠 때는 사본에 적용 → 역추출해 목표와 같은지 확인 → 같을 때만 바꿔 끼운다**(WidgetMcp 조정기). 원본을 손대지 않아 롤백이 구조로 보장된다.
- 부모에 필수 `BindWidget` 이 있으면 빈 캔버스는 컴파일되지 않는다 — 만들 때 컴파일을 건너뛰고 spec 을 적용할 때 컴파일한다.
- **슬롯 종류는 부모 타입이 정한다**(Canvas · Overlay · VerticalBox …). 생략한 값은 엔진 생성자 기본값이다 — Border 슬롯 padding (4, 2) 처럼 0 이 아닌 것이 있다
  (`core/spec.py` 기본값 표). 파이프라인은 다 채운 spec 을 보낸다.

# BindWidget · 생성 C++

- 생성 베이스(`AutoGen/`, 첫 줄 `// AUTO-GENERATED by uigen` 이 있을 때만 덮어씀) + 스텁(없을 때만 만들고 이후 사람 소유) 두 겹. 스텁 클래스 이름은 바꾸지 않는다 —
  WBP 의 부모 경로가 `/Script/AstralBreak.<클래스>` 다.
- **UHT 는 모듈 안에서 헤더 파일 이름이 겹치면 안 된다** — codegen 이 쓰기 전에 검사한다(`HEADER_NAME_TAKEN`).
- 계약(바인딩 목록)의 해시가 같으면 쓰기 · 빌드 · 재기동을 건너뛴다. 바인딩은 추가만 — spec 에서 빠지면 `BindWidgetOptional`, 위젯 클래스가 바뀌면 거부.
- **계약이 바뀐 뒤 지난 `/Game/_AutoGen/*` 의 같은 화면 WBP 를 열면 컴파일 오류가 난다**(그때의 바인딩이라 정상).
- 접히는 자리의 setter(`Set…Visible`)는 **칸 전체(상자)** 를 켠다 — 안쪽 그림만 켜면 빌드는 통과하고 게임에서 안 뜬다 [실측 — README '돌리기' 주의].

# 오프스크린 렌더(`render_widget`)

- **색에 sRGB 가 한 번 더 걸린다.** `FWidgetRenderer(gamma=true)` + `CreateTargetFor(…, true)`(`WidgetRenderer.cpp:81` — `SRGB=false`)로 그리고, 읽은 8 비트 값에 채널마다
  sRGB → 선형을 **한 번** 하면 지정색이 나온다 [실측 3점]. `gamma=false` 는 어두운 쪽이 뭉개져 쓰지 않는다(§12-1 A6-색). 알파는 255(검은 바탕).
- 그릴 때마다 `FlushRenderingCommands` — 그래야 글꼴 · 텍스처가 다 올라온 그림을 읽는다. 2 번 그려 픽셀 차를 같이 낸다.
- **SDF 글꼴은 글리프를 작업 스레드에서 만들고 처음엔 자리표시를 그린다**(`FontCache.cpp:1472` `SpawnWithPlaceholder`, `UpdateCache` 가 바꿔 넣음) [소스]. 에디터 틱이 안 도는
  함수 안에서는 미리 한 번 그리고 쉬며 `UpdateCache` 를 돌린다 — 호출마다 2 초다 [실측]. **상태를 여러 장 그릴 때는 `states[]` 한 호출로 묶는다**(준비 대기 한 번,
  76 장을 한 장씩 그린 것과 PNG 가 바이트까지 같음 [실측 11-24]).
- **머티리얼 셰이더는 첫 그리기에서야 컴파일을 시작하고, 컴파일 중인 배치는 그려지지 않는다.** 저장된 WBP 를 새 에디터에서 처음 그리면 고리(UI 머티리얼)가 빠졌다 [실측] →
  미리 그린 뒤 `GShaderCompilingManager->FinishAllCompilation()` 을 한 번 더.
- 화면 밖으로 완전히 나간 위젯(과 자식)은 Slate 가 그리지 않아 `GetPaintSpaceGeometry` 가 (0, 0, 0, 0) 이다 — '크기 0' 이 아니라 '안 그려짐'으로 센다.
- 검정 바탕만 보면 알파 결함이 숨는다 — 투명도는 회색 · 흰 바탕에서도 본다(§11 'H3').
- 출력 폴더는 `[WidgetMcp] WidgetRenderOutputRoots`(= `Tools/uigen/work/`) 아래 새 · 빈 폴더만. `Saved/` 는 사람도 도구도 못 읽어 쓰지 않는다.

# 텍스처 · 브러시

- Interchange 기본 텍스처 파이프라인은 **2 의 거듭제곱이 아닌 크기를 걸러 낸다**(`bAllowNonPowerOfTwo = false` `InterchangeGenericTexturePipeline.h:70`) → 트랜지언트로 복제해 켠다.
  임포트 뒤 압축 · 그룹(UI) · 밉 없음 · `NeverStream`(`StreamableRenderAsset.h:299`) · sRGB 를 넣고 컴파일을 끝낸 다음 그린다.
- 5.7 에서 `TC_EditorIcon` 의 표시 이름은 `Uncompressed (RGBA8)` 다(`TextureDefines.h:400` — 엔진은 BC7 을 권함). 큰 바탕만 BC7.
- **box 9-slice 의 모서리 두께 = 텍스처 픽셀 × margin**(`ElementBatcher.cpp:857`) — 텍스처가 2 배면 모서리도 2 배로 그려지고 가운데가 눌린다. 크기가 고정된 위젯은 `image` 로 그린다.
- 겹치지 않게 나눈 두 텍스처를 엔진이 따로 늘리면 경계에 검은 절취선이 생긴다 — 투명 픽셀의 색도 가장 가까운 보이는 색으로 채운다(§11 'I 후속').
- ProgressBar 는 `Mask` 면 진행률에서 곧게 자르고 `Scale` 이면 그림 전체를 늘린다. 배경 브러시에 채움과 같은 텍스처를 물들여 넣으면 '빈 자리'가 된다(모양 막대).
- 위젯 회전이 필요한 런타임 아이콘(마름모)은 아직 어휘가 없다.

# 글자

- 한글은 프로젝트 폰트(`F_Pretendard_W` · `F_NotoSerifKR_W`)로. 엔진 기본 글꼴은 한글 bold 가 굵어지지 않는다 [실측]. 빛(`font.glow`)은 SDF 사본(`*_SDF`)이 있어야 한다 —
  `bEnableDistanceFieldFontRasterization` · `UI.SlateSDFText.RasterizationMode=Msdf`(`Config/DefaultEngine.ini`).
- 빛은 글자 상자를 사방 size 만큼 키운다 — 슬롯 padding 을 그만큼 줄인다(음수). 가운데 정렬의 오프셋 = (할당 − 자식)/2 + 앞 여백 − 뒤 여백(`LayoutUtils.h:664`)이라
  자리를 옮길 때 padding 을 양쪽 ± 로 나눈다.
- **작은 글자(획 13 px)는 같은 글꼴도 다시 재면 획 밀도가 ± 15 % 흔들린다** [실측] — 우리가 그린 참고판의 글꼴 값은 `text_ref_layout.yaml` 이 정한다(다시 재지 않음).

# 디자이너 · 저장 · 승격

- UMG 디자이너는 Visibility 를 무시하고 늘 보이게 그린다 — `bHiddenInDesigner` 만 본다 [소스 `Widget.cpp:1482`]. 접힌 위젯이 미리보기를 덮으면 spec `designer_hidden`.
- verify 를 통과할 때까지 저장하지 않는다. 쓰기는 `/Game/_AutoGen/<run_id>/`(git 무시)만, 승격은 `promote_widget` → `/Game/UI/HUD/<화면>/`(**대상이 있으면 거절** — 재승격은
  옛 애셋을 사람이 먼저 치운다).
- `IsValidLongPackageName("/Game")` 은 참이다 — 마운트 루트를 허용 목록으로 받지 않게 따로 막는다.
- `quit_editor` 는 더티면 거절한다. 파이프라인은 `discard_only_under: [/Game/_AutoGen/]` 만 준다.

# 시험

- C++ 를 고치면 빌드 둘(DebugGame · Development `-DisableAdaptiveUnity`) + 에디터에서 `WidgetMcp.`(8 개). 게임 모듈도 고쳤으면 `AstralBreak.` 을 **먼저** 돌린다 —
  PIE 가 로드된 StateTree 를 전부 컴파일해 `StateTreeMcp.*` 가 남긴 깨진 트리가 뒤 PIE 시험을 실패시킨다.
- 어휘를 넓히면 그 어휘의 '밖' 예를 쓰는 시험도 같이 본다(굵기 `Medium` 을 더하자 ImportFont 시험이 낡았다).
