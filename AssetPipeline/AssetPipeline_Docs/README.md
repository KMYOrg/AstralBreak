# AssetPipeline — Architecture v0.1

Claude Code 기반 AI Game Asset & Animation Production Pipeline 설계 문서 패키지. 대상: AstralBreak / UE5.7.4. 실제 구현 코드는 포함하지 않는다.

## 시작 방법

ZIP을 별도 프로젝트 폴더에 풀고 Claude Code를 해당 폴더에서 실행한다. `CLAUDE.md` 및 `START_PROMPT.md`를 읽게 한다. 먼저 자료와 기술 검증을 수행하고 승인 후 구현한다.
