# UI 자동 생성 파이프라인(uigen) 실행 기록 집계

기록 범위 2026-11-14 ~ 2026-11-24 · 만든 것 = `Tools/uigen/summarize.py`(기록을 읽어 세기만 한다 — 같은 기록이면 같은 글) · 설계 = [ui-autogen-pipeline.md](ui-autogen-pipeline.md)

컨셉아트 한 장을 받아 에셋 → C++ 바인딩 → WBP → 렌더 검증까지 사람 개입 없이 도는 파이프라인의 실행 기록이다. LLM 은 배치 분석 · 실패 원인 설명 · 정정안(과 지금은 끈 외형 검토)에만 쓰고, 합격은 규칙 · 수치 게이트가 정한다.

**읽을 때 주의**

- 지표 줄은 run 210개 전부지만, run 폴더는 정리하고 **59개만 남았다**(실패 · 중간 run 을 많이 지움). 3 ~ 7 절은 남은 것의 값이고 **전체 통과율이 아니다**.
- `CombatHUD` run 중 2026-11-23 앞의 112개는 대부분 파이프라인을 만들던 시험이다(시험 컨셉 · 일부러 깨뜨린 run 포함). 화면 이름만으로 게임 run 과 가를 수 없어 통과율을 내지 않는다. `Probe…` 는 검증 전용 화면이다.
- 초기 3줄에는 run 결과(status)가 없어 '그 밖'으로 셌다. 일부러 결함을 넣은 run 은 6개다.
- 'USD' 는 API 정가로 환산한 값이다 — 구독 계정이라 과금이 아니다. 시간은 한 대의 PC 에서 잰 값이고 다른 작업과 겹쳤을 수 있다.
